| Conformance measurement | The per-API coverage floors measured served surface instead of pattern collisions (BUG-2651). Google Cloud and Microsoft Azure counted a documented method as covered only when a probe of the running simulator reached a handler that answered; Amazon Web Services credited a legacy query action to the service whose registrar actually mounted it, replacing a fold that gave every versioned service the whole unversioned bucket. A Go mux miss, a method mismatch, or a structured "method unknown" read as uncovered, a structured `404` for an absent resource as covered, and write probes carried malformed bodies so none could mutate state. Each cloud kept a soundness test that failed if the probe stopped authenticating or an unmounted URI stopped reading as a miss. Google Cloud measured 4054 of 5397 documented methods (Spanner 58 of 198, its REST session data plane never having been served), Azure 1878 of 2612 (Blob 17 of 69), and every Amazon Web Services floor was unchanged. |

The Azure Files data plane wrote where an Azure Container Apps workload bind-mounts it, replacing two implementations of which the disk-backed one was unreachable. The relying-party matrix drove the full story — browser sign-in, then `aws`/`az`/`gcloud` each verified vendor-natively, then logout. |

Google Cloud gained a real Cloud Resource Manager slice — replacing a faked partial v3 surface that synthesized projects and operations — with v1+v3 lifecycle, Cloud Billing reads, ID-or-number resolution, 403-without-disclosure, soft-delete, and the console's real project-picker chip threading the selected project through every page; SDK, gcloud, and `google_project` Terraform coverage landed together. | Console credential minting | All three simulator consoles let a Shauth-authenticated operator mint the credentials their vendor CLI needs, through the operator's federated credentials calling the cloud's real APIs — AWS IAM users + Create access key (Query protocol, browser-side SigV4, one-time secret disclosure), Google Cloud service accounts + one-time `privateKeyData` JSON key download, Microsoft Entra app registrations + Certificates & secrets (Graph `applications`/`addPassword`). Token minters, discovery/JWKS, metadata/IMDS, health, OCI registries, and the anonymous flows (`AssumeRoleWithWebIdentity`/SAML, presigned URLs, S3 public reads) stayed exempt. Every SDK/CLI/Terraform suite, the sockerless backends (their `WithoutAuthentication`/`fakeCredential` fakes replaced with a real GCP metadata token source and Azure `DefaultAzureCredential`), and the relying-party provisioning authenticated for real; the console browser e2e reached the enforcing simulator unauthenticated, so its data-render assertions moved to the authenticated relying-party path.
