CLI tests proved each minted credential authenticates the real vendor CLI (and wrong/tampered/revoked material is rejected); the Shauth relying-party browser matrix mints on the AWS and Google Cloud consoles with one-time disclosure asserted (the harness's federation role gained `iam:*`, which the simulator's IAM enforcement correctly required), and the full local matrix passed with its true exit code observed. The Azure portal's browser-side federation exchange is same-origin-only (real Microsoft Entra serves no CORS for `client_credentials`), so its browser minting flow is staged with the deployment-phase broker work (BUG-2640); Entra minting is proven by the Azure SDK and az CLI suites. |
| Skip-if-absent gate + sweep | `scripts/check-no-tool-absent-skips.sh` gained two shapes beyond `t.Skip` — a `fmt.Print*`/`log.Print*` tool-absent phrase and a `LookPath`-anchored `os.Exit(0)` — closing the TestMain-level silent-skip hole, and exempted skips that self-identify as platform/kernel-capability gates so a GOOS gate reading "not available" was not a false positive. Every remaining tool-absent skip resolved to install-or-fail-loud: the Google Cloud CLI suite installed a pinned release when `gcloud` was absent (the Azure CLI suite failed loud, `az` having no clean TestMain install); the six vestigial `docker CLI not available` guards (Docker already guaranteed by each TestMain's image build) were removed while the netns capability gates stayed; and the `session-manager-plugin`, `git`, `gcloud` (Firestore), and `nsenter` skips became `t.Fatal` against CI-provided tools. |

| Credential enforcement | All three simulators verified caller credentials on their data planes as the real clouds do (BUG-2625): AWS recomputed and verified the SigV4 signature at the awsjson/query control plane and S3 (persisting `ASIA` temporary-credential secrets, seeding a bootstrap account credential); Google Cloud and Azure verified the bearer's signature, issuer, audience, and expiry against the simulator-minted token (GCP consolidated to one RS256 key + published JWKS; Azure reused its RS256 verifier and added the audience check). Token minters, discovery/JWKS, metadata/IMDS, health, OCI registries, and the anonymous flows (`AssumeRoleWithWebIdentity`/SAML, presigned URLs, S3 public reads) stayed exempt. Every SDK/CLI/Terraform suite, the sockerless backends (their `WithoutAuthentication`/`fakeCredential` fakes replaced with a real GCP metadata token source and Azure `DefaultAzureCredential`), and the relying-party provisioning authenticated for real; the console browser e2e reached the enforcing simulator unauthenticated, so its data-render assertions moved to the authenticated relying-party path.
