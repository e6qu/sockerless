| 2635 | P1 | simulator console UIs read an invented endpoint with a trimmed shape | the operator UI reads sockerless-only `/sim/v1/*` dashboard routes that no cloud serves, returning hand-picked fields | Each simulator console reads bespoke `/sim/v1/<service>` JSON endpoints (added in Phase 75 to stand a UI up before solving auth) instead of the real cloud APIs the sim already serves, so it displays a sockerless-invented path and a trimmed resource shape — a Cloud Run job shows four fields where the real resource carries fifteen, and a Cloud Storage bucket's properties are dropped entirely. The Google Cloud slice landed first: the Security Token Service token exchange, the console credential broker, and the Cloud Run jobs view reading the real `/v2/.../jobs` list and detail with the invented endpoint deleted.
